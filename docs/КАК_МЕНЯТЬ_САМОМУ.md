# Как менять интерфейс самому (без ИИ и без кода)

Весь новый интерфейс теперь — обычные **сцены (.tscn)**, **Theme** и **ресурсы (.tres)**.
Открываешь сцену в Godot, выделяешь узел, меняешь в **Инспекторе** — как с любой вашей сценой.
Код нужен только для поведения, и его настройки вынесены в инспектор (группы `@export`).

> Используй ТОЛЬКО эту папку `editor_ui/`. Папки `pack/`, `terminal/`, `effects/`, `health/`, `inventory/`
> из прошлых сообщений — устаревшие версии «всё в коде». Если положить их вместе, будут конфликты имён классов.

---------------------------------------------------------------------------------------------------

## 1. Установка (один раз, ~10 минут)

Скопируй содержимое папки в проект с сохранением путей (заменить файлы при вопросе). Потом в редакторе:

| Что | Что сделать |
|---|---|
| **Выбор планеты** | Ничего. `planer_chooser.tscn` заменён «на месте» с тем же внутренним UID — сцена корабля и `Show_Child` находят его как раньше. |
| **Окно заданий** | Открой `GUI.tscn` → ПКМ по корню → **Instantiate Child Scene** → `misc/UI/QuestTerminal/quest_terminal.tscn`. Старый узел `QUESTBOX` скрой (глазок) или удали. |
| **Эффекты** | В `GUI.tscn` удали старый узел `EffectDisplay` → **Instantiate Child Scene** → `misc/UI/Effects/effect_display.tscn` → **переименуй новый узел точно так же, как был старый** (чтобы `player.gd` его находил). Файл `EffectIcon.tscn` больше не нужен. |
| **Полоска жизни** | Файл `health_bar.gd` заменён «на месте», скрипт остаётся прикреплённым к узлу `HealthBar`. Дочерние узлы `DelayedBar`, `CurseBar`, `HeartIcon` можно удалить. |
| **Инвентарь/хотбар** | Открой `Inventory.tscn` → ПКМ по корню `Inventory` → **Instantiate Child Scene** → `misc/UI/InventoryUX/inventory_ux.tscn`. Строк в код добавлять не нужно. |
| **Переводы** | Замени `common/Translations/strings.json` (в нём всё прежнее + новые ключи). |

Если Godot просит удалить/пересоздать `.uid` файлы — соглашайся, это нормально.

## 2. «Хочу изменить… → иду сюда»

### Общий вид терминалов (цвета панелей, рамки, шрифты, кнопки)
`common/Themes/terminal_theme.tres` → открой двойным кликом, внизу вкладка **Theme**.
Там «варианты типов» (Type Variations): `TerminalScreen`, `TerminalScreenBright`, `TerminalMetal`,
`TerminalButton`, подписи `TerminalTitle / TerminalText / TerminalHeading / TerminalDim / TerminalSmall…`,
подсказки эффектов `TerminalTipBuff / Debuff / Passive`.
Поменял цвет рамки в `TerminalScreen` — поменялись все экраны во всех окнах.
Размеры рассчитаны на холст **480×270**.

Чтобы у конкретного узла был другой вид — выбери узел → инспектор → **Theme Type Variation** (выпадающий список).

### Окно заданий (`quest_terminal.tscn`)
- **Положение/размер** — узел `Panel` (якоря и отступы в инспекторе, или тянуть мышью в 2D-вкладке).
- **Шрифт тела** — узел `Body` → Theme Type Variation `TerminalBodySmall` (6 px) или `TerminalBody` (9 px); или Theme Overrides → Font Sizes.
- **Сколько секунд показывать при входе на планету, сколько целей, цвета строк, тексты** — выдели **корневой узел** `QuestTerminal` → инспектор, группы «Тайминги», «Вид», «Цвета строк», «Тексты».
- **Клавиша** — Project Settings → Input Map → действие `ShowQuests` (если его нет, создаётся само: Tab).
- **Убрать бледную подсказку в углу** — галочка `Show Idle Chip`.

### Выбор планеты (`planer_chooser.tscn`)
- **Добавить планету:** ФайлСистема → ПКМ в `common/Resources/PlanetInfo/` → **Create New → Resource → PlanetInfo**
  (или продублируй `Vehana.tres`). Заполни: `Id` (ключ сцены в SceneRegistry), `Fuel Cost`, `Tint`,
  `Icon Region` (какая планета из атласа `Planet.png`), `Type Key`, `Description Key`.
  Потом корневой узел `PlanerChooser` → инспектор → список **Planets** → **Add Element** → перетащи свой `.tres`.
  Новая строка появится сама.
- **Какая картинка у планеты:** `Icon Region` (x, y, ширина, высота). Свободные картинки в атласе: ледяная `104,8,17,17`,
  лавовая `60,80,12,12`, звезда `4,53,41,41`, пёстрая `49,50,19,19`.
- **Тексты досье** — это ключи перевода: впиши ключ в `Type Key` / `Description Key` и добавь перевод в `strings.json`.
- **Анимация планеты** (орбита, парение, линия скана, проектор) — узел `Viewer`: галочки и числа в инспекторе.
- **Размер/расположение экранов** — узлы `Screens`, `ListScreen`, `ViewScreen`, `InfoScreen` (Size Flags → Stretch Ratio = ширина).
- **Эффект включения монитора** — настройки узлов `ListScreen/ViewScreen/InfoScreen`; **строчная развёртка** — дочерний узел `Scan` в каждом экране.
- **Цвета статусов, длительность запуска** — корневой узел `PlanerChooser`.
- **Строка списка** (шрифты, высота, цвета) — сцена `planet_row.tscn`.

### Эффекты (`effect_display.tscn`, `effect_slot.tscn`, `effect_tooltip.tscn`)
- **Размер значка, цвета рамок (бафф/дебафф/экипировка), порог мигания** — корневой узел сцены `effect_slot.tscn`.
  `Icon Scale` = во сколько раз увеличить иконку 16×16 (1, 2, 3…).
- **Какие эффекты считаются дебаффами** — корневой узел `EffectDisplay` → `Debuff Types`.
- **Иконка для типа эффекта** — `Type Icons` (словарь «тип → картинка»). У самого эффекта иконка в приоритете.
- **Вид подсказки при наведении** — сцена `effect_tooltip.tscn` (обычные Label и PanelContainer).
- **Положение ленты** — выключи `Follow Health Bar` и двигай узел как хочешь.

### Полоска жизни (узел `HealthBar` в `GUI.tscn`)
Выдели узел → инспектор. Группы: «Анимация» (след урона, тряска, частота сердцебиения, засечки…),
«Рамка и фон», «Виньетка при низком здоровье», цвета заливки/следа/лечения/проклятия, режим цифр, порог тревоги.
Градиент виньетки — сцена `misc/UI/HealthBar/health_vignette.tscn` → узел `Rect` → его Texture → Gradient.

### Инвентарь и хотбар (`inventory_ux.tscn`)
- **Что показывать на хотбаре** (номера, рамка выбора, название предмета, вспышка, тревога прочности, «FULL») и тайминги —
  узел `HotbarOverlay` (галочки).
- **Цвета редкости** — корневой узел `InventoryUX` → `Quality Colors`; **прозрачность подложки** — `Rarity Alpha` (0 = выкл).
- **Где стоят счётчик «Bag 7/15», кнопка Sort, подсказка** — группа «Положение виджетов» на корневом узле.
- **Вид кнопки Sort и подписей** — узлы `SortButton`, `CapacityLabel`, `HintLabel` (Theme Overrides).

## 3. Как сделать НОВОЕ окно в этом стиле
1. Новая сцена с корнем `Control` → в инспекторе **Theme** → перетащи `terminal_theme.tres`.
2. Добавь `PanelContainer` → Theme Type Variation = `TerminalScreen` (или `TerminalMetal` для корпуса).
3. Внутри — `Label` с вариантом `TerminalTitle` / `TerminalText` / `TerminalDim`, `Button` с `TerminalButton`.
4. Хочешь «монитор» — добавь в панель последним ребёнком узел `TerminalScan` (развёртка) и скрипт `terminal_screen.gd` на панель (эффект включения).

## 4. Что всё ещё нарисовано кодом (и почему)
Иконки-значки эффектов, строки списка планет, витрина планеты, сердце/полоска и оверлей хотбара **рисуются** скриптом
(`_draw`) — это пиксельная графика с анимацией, которую обычными узлами не собрать. Но все цвета, размеры и включатели
у них вынесены в инспектор (см. выше), поэтому менять их можно так же мышкой. Править сам алгоритм рисования нужно
только если хочешь принципиально новое поведение.

## 5. Одна правка вне UI: предмет не должен пропадать молча
В `GlobalManager.gd`, в `pickup_item()`, ветка `else` (инвентарь полон) сейчас только печатает в консоль.
Добавь строку, чтобы игрок увидел причину:
```gdscript
GameJuice.banner(Loc.t("Inventory full"), Loc.t(item_data.item_name), Color(1.0, 0.5, 0.4), 1.4)
```
(ключ `Inventory full` уже есть в `strings.json`).
